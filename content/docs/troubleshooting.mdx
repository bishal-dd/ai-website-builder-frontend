# Troubleshooting

This guide helps you fix common issues while using Sencill AI.

If something does not work as expected, start with the issue closest to your problem.

## Website generation is taking too long

Website generation can take time depending on your input, selected website type, number of pages, and current system load.

If generation takes too long:

- Wait a few more minutes.
- Make sure your internet connection is stable.
- Avoid refreshing the page immediately.
- Check if the website appears in your dashboard.
- Try generating again if the process fails.

If the issue continues, contact support.

## Website generation failed

Website generation can fail because of:

- Missing required information
- Very short or unclear business description
- Internet connection issue
- Server issue
- AI service delay
- Too many requests at the same time

To fix it:

1. Review your business details.
2. Make sure required fields are filled.
3. Use a clear business description.
4. Try again after a few minutes.

Example of a better description:

> Create a modern website for a Bhutan-based travel agency offering cultural tours, trekking packages, festival tours, and custom itineraries for international travelers.

## Website preview is not loading

If the website preview does not load:

- Refresh the page.
- Check your internet connection.
- Make sure you are signed in.
- Open the website again from your dashboard.
- Try another browser if needed.

If the preview still does not load, contact support.

## Text changes are not saving

If text edits are not saving:

- Click outside the edited text area after making changes.
- Wait a few seconds for the update to save.
- Check your internet connection.
- Avoid refreshing immediately after editing.
- Try signing out and signing in again.

If the issue continues, contact support.

## Image upload failed

Image upload can fail because of:

- Unsupported file format
- File size is too large
- Internet connection issue
- Upload service delay
- Server issue

To fix it:

- Use JPG, PNG, or WEBP images.
- Try a smaller image file.
- Make sure the image is not corrupted.
- Check your internet connection.
- Upload again after a few moments.

For best results, use clear and high-quality images.

## Logo upload failed

If your logo upload fails:

- Use PNG, JPG, or WEBP format.
- Make sure the logo is clear.
- Avoid very large files.
- Try uploading again.
- Use a logo with a transparent background if possible.

## AI chat editor is not responding

If the AI chat editor does not respond:

- Check your internet connection.
- Make sure your request is clear.
- Try a shorter request.
- Wait a few moments and try again.
- Refresh the page only if needed.

Example of a clear request:

> Make the homepage hero section more premium and focus on hotel room bookings.

## New page was created but not visible

If a new page is created but you cannot find it:

- Check the page selector if available.
- Refresh the preview.
- Look for the page in your website structure.
- Ask the AI chat editor to link the page in the navigation.

Example:

> Add the new Services page to the navigation menu.

Or:

> Link the homepage Services section cards to the Services page.

## Publish button is not working

If the **Publish** button does not work:

- Make sure your website has finished generating.
- Review required website information.
- Check your internet connection.
- Refresh the preview page.
- Try again after a few moments.

If the issue continues, contact support.

## Domain search is not working

If domain search does not work:

- Check your internet connection.
- Make sure the domain name is entered correctly.
- Try a different domain name.
- Avoid using `https://`, spaces, or special characters.
- Try again after a few moments.

Correct example:

```txt
yourbusiness.com
```
