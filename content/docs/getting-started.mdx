# Getting Started

Sencill AI helps you create a website by entering your business details and letting AI generate the first version for you.

After the website is generated, you can preview it, edit the content, change images, and publish it when you are ready.

## How Sencill AI works

The basic flow is:

1. Create an account.
2. Sign in to your dashboard.
3. Start a new website.
4. Enter your business details.
5. Choose the type of website you want to create.
6. Let the AI generate your website.
7. Preview and edit the result.
8. Publish the website when it is ready.

## What you can create

Sencill AI can help create different types of websites, such as:

- Business websites
- Portfolio websites
- Restaurant websites
- Hotel websites
- Travel agency websites
- Shop or product websites
- Marketing pages

The available website types may depend on the options currently shown in the website generator.

## Before you generate a website

To get a better result, prepare a few details about your business.

Useful information includes:

- Business name
- Short business description
- Services or products
- Target customers
- Preferred website style
- Contact details
- Images or logo, if available

The more clear your input is, the better the generated website will be.

## Example business description

A weak description:

> I need a website for my company.

A better description:

> Create a modern website for a Bhutan-based travel agency offering cultural tours, trekking packages, festival tours, and custom itineraries for international travelers.

A better description gives the AI more context and helps it create a more useful website.

## After your website is generated

Once the website is generated, you can:

- Preview the website
- Edit text directly
- Change images
- Request changes using the AI chat editor
- Regenerate parts of the website
- Publish the website online

## Saving your progress

Your generated websites are saved in your account, so you can return to them from your dashboard.

If you do not see your website, check that you are signed in with the same account used to generate it.
